# AI Assistant for Game 🎮🤖

โปรเจกต์ AI ผู้ช่วยเล่นเกมแบบโมดูลาร์ ที่สามารถรองรับเกมได้หลากหลายผ่านไฟล์กำหนดค่า (Config) โดยไม่ต้องแก้โค้ดหลักเมื่อเพิ่มเกมใหม่

## 🎯 เป้าหมาย
สร้าง AI ที่สามารถ:
- 👁️ **Perception** — รับรู้สถานะของเกม (OCR, ภาพหน้าจอ, หรือ API)
- 🧠 **Reasoning** — ตัดสินใจเลือกการกระทำด้วย LLM
- 🎮 **Action** — ลงมือทำผ่านการจำลองคีย์บอร์ด/เมาส์ หรือเรียก API
- 💾 **Memory** — จดจำประสบการณ์เพื่อนำมาใช้ซ้ำในอนาคต
